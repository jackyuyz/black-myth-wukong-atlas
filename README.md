# 黑神话：悟空文化地图

一个中文静态文化探索网站：沿着游戏章节阅读游戏中的呈现、《西游记》中的出处与改编，以及有证据支持的现实文化遗产。

## 当前可用

- 中文首页、六回章节页、关于与来源页，共 10 条预渲染路由。
- 第一回原创路线示意图：12 个可点击文化点、3 个连接点，支持拖拽、缩放、复位、类型与知识层筛选。
- 六回共 22 张文化阅读卡。其余五回先提供无坐标的意境总览与选篇，不宣称完整地图。
- 第三回亢金龙／府城玉皇庙彩塑的文学与现实文化对照，含照片署名、许可、证据范围。
- 桌面阅读抽屉、移动端全屏阅读、键盘焦点恢复、减少动态效果支持。
- 所有阅读卡均写入静态 HTML；关闭 JavaScript 也可用原生折叠条目读正文。

## 运行

需要 Node.js 22+。

```bash
npm ci
npm run dev
```

生产构建与预览：

```bash
npm run build
npm run preview -- --port 4173
```

`npm run build` 先运行数据验证、TypeScript 和反例测试，再构建浏览器与临时服务端产物，最后将全部路由预渲染到 `dist/`。`.ssr/` 只是构建工具，不需要线上服务器。

## 内容与门槛

- `src/data/chapters/`：每回中文内容、知识层、引用和图上位置。
- `src/data/sources.json`：保留原知识库来源编号的统一索引。
- `src/data/media.json`：实际公开素材及权利记录。
- `src/types/schema.ts`：严格的数据结构和中文展示标签。
- `scripts/validate-data.ts`：引用、枚举、坐标、拓扑、纪实素材与权利门槛；CI 与 prebuild 不可跳过。
- `assets/research/chapter-01-topology.json`：独立复核过的第一回线框。地图变更必须同步证据与复核记录。
- `ASSET_GAPS.md`：缺失素材及当前替代呈现。
- `IMPLEMENTATION_STATUS.md`：实现边界与验证记录。

新增内容字段应先写入 `DEVELOPMENT_SPEC.md`，同次变更增加 schema 及语义验证。不能为通过构建放宽引用或权利门槛。

## 静态部署

可将 `dist/` 发布到支持目录式静态 HTML 的根域名或子域名。无需 SPA 回退重写；每个章节均有真实的 `index.html` 与无尾斜线部署使用的 `.html` 镜像，另生成 `404.html`。提供了 Vercel 静态配置，但本轮没有执行线上部署。GitHub Pages 若使用仓库子路径，需要先统一设置资源基路径与路由 basename，当前默认根路径。

按仓库安全规则，构建设置 `emptyOutDir: false`，不自动清空目录。重复构建可能保留旧的带哈希资源；发布前使用全新检出的构建目录（CI 默认如此）。不得批量删除研究素材或目录。
