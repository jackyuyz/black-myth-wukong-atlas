# 游戏素材研究区

本目录保存从第一方页面及第三方攻略媒体取得的《黑神话：悟空》高清图片研究副本，目的是内部视觉研究、角色与场景识别、章节风格梳理以及未来授权候选整理。

## 权利边界

- 所有文件的 `licenseStatus` 均为 `permission-required`。
- 所有文件的 `storageScope` 均为 `research-only`。
- 所有文件的 `useInPublicBuild` 均为 `false`。
- 保存原图不代表取得再发布、改编、商业展示或品牌使用授权。
- 构建脚本与前端代码不得扫描或自动导入本目录。
- 对外发布前，应取得权利人书面许可，或替换为团队自有且权利边界明确的实机截图。

## 身份标注原则

文件名与画面内制作代号只作为发现线索。早期的“火刀狼”“灵虚道长”等设定不可在没有进一步证据时直接等同于最终版广智或灵虚子；清单通过 `identityConfidence` 和 `subjectCandidateZh` 明确记录这类不确定性。
