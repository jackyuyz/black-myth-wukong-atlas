# 第三方实机与游戏界面研究参考

本目录保存第三方攻略媒体发布的《黑神话：悟空》实机截图、物品界面与行旅图。图片已经人工核对主体，只用于内部研究、画面识别、章节叙事与后续授权候选整理。

## 权利边界

- 全部条目均为 `permission-required`、`research-only`、`useInPublicBuild: false`。
- 第三方页面可公开访问，不代表本项目获得复制、改编或重新发布的权利。
- 游戏画面还可能同时涉及游戏科学、发行方、截图作者或媒体平台的权利。
- 前端、静态站点生成器和公开构建不得扫描或自动导入本目录及对应的 `assets/optimized/game/community-reference/`。
- 对外使用前，须取得适用许可，或替换为团队合法持有游戏版本中的自有截图，并记录平台、版本、截图者、地点、任务状态与裁切方式。

## 使用原则

1. 这些图片可以回答“画面里是谁、是什么界面、属于哪一回”，不能单独证明现实取景或古建对应关系。
2. 玩家或媒体加滤镜、调曝光、裁切后的图片只能作气氛参考；角色、地点和物品身份仍需以游戏内游记、影神图或无修改自有截图复核。
3. 项目 UI 可研究游戏的色调、留白、材质和信息层级，但不得逐像素复制 HUD、物品框、菜单结构、图标或 Logo。
