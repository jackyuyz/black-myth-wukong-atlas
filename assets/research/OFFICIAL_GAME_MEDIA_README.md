# 官方游戏媒体链接库

`official-game-media-links.json` 从游戏科学官网公开页面使用的前端资源路径中提取，当前包含概念图、截图和壁纸链接。

这些条目属于**游戏视觉研究与授权候选**，不是项目可直接发布的素材：

- `licenseStatus` 统一为 `permission-required`；
- 80 条桌面版高分辨率素材已在 `assets/source/game/official-reference/` 保存研究副本；
- 26 条移动端重复壁纸只保留链接，没有重复保存；
- 所有本地副本的 `storageScope` 为 `research-only`，`useInPublicBuild` 为 `false`；
- 86 张本地官方参考的逐图信息另见 `game-reference-assets.json`，其中还包括 6 张 Steam 官方商店截图；
- 后续可以用它们确认角色、敌人、关卡与物品的实际视觉，也可以据此列授权申请清单；
- 如果团队使用自己录制的实机截图，应另建条目，记录游戏版本、平台、任务位置、截图者、裁切方式与发布依据。

来源：<https://gamesci.cn/wukong/>。文件名只能作为发现线索，不足以独立证明最终游戏中的角色身份或章节归属。

Steam 官方商店来源：<https://store.steampowered.com/app/2358720/Black_Myth_Wukong/>。
