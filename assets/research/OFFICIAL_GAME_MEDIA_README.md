# 官方游戏媒体链接库

`official-game-media-links.json` 从游戏科学官网公开页面使用的前端资源路径中提取，当前包含概念图、截图和壁纸链接。

这些条目属于**游戏视觉研究与授权候选**，不是项目可直接发布的本地素材：

- `licenseStatus` 统一为 `permission-required`；
- `localBinaryStored` 与 `useInPublicBuild` 均为 `false`；
- 仓库没有保存这些官方图片的二进制副本；
- 后续可以用它们确认角色、敌人、关卡与物品的实际视觉，也可以据此列授权申请清单；
- 如果团队使用自己录制的实机截图，应另建条目，记录游戏版本、平台、任务位置、截图者、裁切方式与发布依据。

来源：<https://gamesci.cn/wukong/>。文件名只能作为发现线索，不足以独立证明最终游戏中的角色身份或章节归属。
